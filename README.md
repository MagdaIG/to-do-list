# To-Do List

Aplicación móvil de tareas desarrollada con Ionic Framework y TypeScript. Permite crear, listar y eliminar pendientes con una interfaz responsiva y adaptada a iOS y Android. Proyecto orientado a la práctica de SPA móviles con componentes reutilizables y arquitectura basada en Ionic.

## Tech Stack

- Ionic Framework
- TypeScript
- Angular

## Features

- Create, list and delete tasks
- Responsive interface adapted for iOS and Android
- Reusable components and Ionic-based architecture

## Getting Started

```bash
git clone https://github.com/MagdaIG/to-do-list.git
cd to-do-list
npm install
ionic serve
```
